# Just Text Translate (JTT)

Удобный, быстрый и точный инструмент перевода текста на экране для Windows. 
Позволяет мгновенно распознавать и переводить текст в играх, видео, PDF-документах, интерфейсах программ и любых изображениях, где текст нельзя скопировать обычным способом.

## 🚀 Основные возможности

- **🎯 Обвести и перевести (`Ctrl + Alt + T`)**:
  Выделите любую область экрана рамкой — программа мгновенно распознает текст с помощью встроенного OCR-движка и отобразит удобную карточку перевода поверх всех окон.
  *(Не сворачивает полноэкранные игры и приложения — оверлей работает без потери фокуса).*

- **💬 Окно переводчика (`Ctrl + Alt + Y`)**:
  Компактное окно быстрого перевода текста:
  - Автоматическое определение исходного языка
  - Кнопка быстрого копирования результата
  - Добавление перевода в личный словарь в один клик
  - Адаптивный размер окна по объёму текста

- **📖 Личный словарь (`Ctrl + Alt + D`)**:
  Встроенная база сохранённых слов и выражений (SQLite):
  - Разделение по языковым парам (например, `en → ru`, `ru → en`)
  - Поиск, фильтрация, пагинация и сортировка
  - Возможность добавлять заметки к словам прямо из карточки перевода
  - Импорт и экспорт словаря в CSV

- **🌐 Умное автопереключение языков**:
  Настройте пару языков перевода в Настройках (например, Русский ⇄ English) — программа автоматически определит язык оригинала и переведет на второй язык.

- **⚡ Локальный перевод офлайн (CTranslate2)**:
  Возможность перевода без подключения к интернету с помощью встроенных нейросетевых моделей (Helsinki-NLP Opus-MT).

- **🔄 Автообновление в один клик**:
  Приложение само проверит наличие новых версий и аккуратно предложит обновиться прямо из системного трея или окна Настроек.

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| **`Ctrl + Alt + T`** | Обвести область экрана и перевести |
| **`Ctrl + Alt + Y`** | Открыть окно переводчика |
| **`Ctrl + Alt + D`** | Открыть личный словарь |

## 💻 Системные требования

- **Операционная система**: Windows 10 / Windows 11 (64-bit)
- **Интернет**: Не требуется при использовании встроенных моделей перевода

## 📥 Установка

1. Скачайте последнюю версию установщика [**Setup.exe**](https://github.com/nexxxyz/Just-Text-Translate/releases/latest/download/Setup.exe).
2. Запустите файл `Setup.exe` и следуйте подсказкам мастера установки.
3. Программа появится в системном трее (рядом с часами Windows) и будет готова к работе по горячим клавишам.
